# PIXEL ADVENTURE 开始封面设计

## 用途

为 2Dpixel Unity 项目制作一张 16:9 横版像素游戏开始封面图，作为开始场景的背景主视觉。开始按钮等交互 UI 后续由 Unity 叠加，不直接烘焙进图片。

## 视觉方向

- 延续现有关卡的明亮像素平台游戏风格。
- 使用浅灰色菱形纹理背景、鲜绿色草皮和暖棕色土块平台。
- 保持清晰硬边像素、有限色板和轻快可爱的氛围。
- 参考用户提供的游戏场景截图，但重新组织为封面构图，不复制 Unity 编辑器界面。

## 构图与元素

- 画面比例：16:9 横版。
- 标题 `PIXEL ADVENTURE` 位于上方中央，采用醒目的像素字体。
- 白色小角色位于中央偏左，呈跳跃姿态，作为视觉焦点。
- 中景设置错落的草地土块平台。
- 使用苹果、金币、少量尖刺和右侧终点门作为关卡元素。
- 中央下方保留相对干净的区域，方便 Unity 后续放置“开始游戏”等按钮。

## 约束

- 不出现 Unity 编辑器窗口、工具栏、调试信息或鼠标指针。
- 不生成“开始游戏”按钮或其他交互 UI。
- 除 `PIXEL ADVENTURE` 外不加入其他文字。
- 不使用写实、3D、矢量渐变或高分辨率绘画笔触。
- 不添加水印、品牌标志或与现有关卡无关的角色。

## 验收标准

- 第一眼可识别为与当前 2Dpixel 关卡相同视觉体系的像素平台游戏。
- 标题清晰、拼写正确。
- 主角、平台、苹果、金币、尖刺和终点门均清楚可辨。
- 下方有足够留白，可叠加开始菜单按钮。
- 画面可直接作为横版开始场景背景使用。
